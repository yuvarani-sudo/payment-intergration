💳 Payment Gateway Integration Project

A full-stack payment application built using Node.js (backend) and React.js (frontend) with seamless online payments powered by Razorpay.

🚀 Project Overview

This project demonstrates how to integrate a secure payment gateway into a modern web application. Users can initiate payments, and the system processes transactions using Razorpay’s API.

It covers:

Payment order creation
Secure transaction handling
Frontend checkout integration
Backend verification
🛠️ Tech Stack

Frontend:

React.js
Axios
Razorpay Checkout

Backend:

Node.js
Express.js
